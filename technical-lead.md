# Technical Lead

**Experience:** 5–7 years
**Employment:** Full Time

- Bachelor/Honors in Computer Science, Software Engineering, Information Technology, or related field.

## Required Professional Qualifications

- 5–7 years professional software engineering experience with advancement into technical leadership roles.
- Proficiency in modern front-end tech: JavaScript, TypeScript, React, Angular, or Vue.
- Extensive back-end experience: Node.js, Python, Java, or C#, plus microservices architecture.
- Strong knowledge of relational and non-relational databases: schema design, query optimization, data persistence.

- Solid understanding of cloud deployment, containerization, CI/CD pipelines.
- Strong technical leadership, structured problem-solving, written communication skills.

- Led distributed/cross-functional engineering teams in agile environments.
- Serverless architecture, event-driven architecture, messaging system integrations.
- Application security standards, data encryption, vulnerability assessment.
- Certification in enterprise software architecture, cloud platforms, or technical project management.

- Provide technical direction/leadership across front-end and back-end teams.
